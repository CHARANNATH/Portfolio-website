# Public Assets

## Adding Your Resume

To add your resume for download:

1. Place your resume PDF file in this directory
2. Name it: `Charannath_Chowdary_Resume.pdf`
3. The portfolio will automatically allow users to download it

## Project Images

Add project preview images to this directory:

- Photo Puzzle Game preview
- Pyramid Game preview
- Tic Tac Toe Game preview

The images should be:

- Resolution: 500x300 pixels (or similar aspect ratio)
- Format: JPG, PNG, or WebP
- Size: Optimized for web (< 200KB recommended)
